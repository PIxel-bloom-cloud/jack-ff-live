# JACK FF LIVE — HTML, CSS & JavaScript

## Open in Visual Studio Code
1. Extract this folder.
2. Open the `jack-ff-live-complete` folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Choose **Open with Live Server**.

No Node.js, npm, React or build step is required.

## Project files
- `index.html` — page structure and your social links
- `css/style.css` — layout, typography, hero, cards and character image
- `css/animations.css` — background and character animations
- `css/responsive.css` — tablet and mobile styles
- `js/background.js` — animated star field and mouse parallax
- `js/navigation.js` — mobile navigation
- `js/main.js` — active section navigation
- `images/jack-ff-live-logo.jpg` — channel logo
- `images/jack-gaming-character.jpg` — uploaded gaming character
